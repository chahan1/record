# 立即錄音機（record）

Android 錄音 App（Kotlin）。

## 功能
- 開啟 App 後自動開始錄音（可開關）
- 錄音來源：麥克風／其他 App 的聲音（Android 10+）／兩者混合
- 輸出 AAC（.m4a）；前景服務，螢幕關閉仍持續錄音，通知列可暫停／停止
- 錄音清單：App 內播放（可拖曳進度）、重新命名、分享、刪除
- 批次刪除：按「選取」或長按任一筆，勾選後一次刪除
- 分段錄音：可設定每 15／30／60 分鐘自動切成一個檔案（檔名 _p01、_p02…），每段結束後可自動備份
- 雲端備份到 Google Drive：上傳缺少或不一致的檔案，並用 MD5 檢查雲端是否完整

## 之後
- MP3 格式（目前只有 AAC）

## 編譯
推上 GitHub 後，Actions 會自動編譯，APK 放在 Releases 的 `latest`。
簽署金鑰 `app/record.jks` 固定不變，所以新版 APK 可直接覆蓋安裝。

## 手機設定（小米 HyperOS）
安裝後到 設定 → 應用程式 → 立即錄音機：
1. 省電策略 → 無限制
2. 自動啟動 → 開啟
3. 通知 → 允許

## 設定 Google Drive 備份（只需做一次）
App 用一個 Apps Script「中繼站」取得短效權限（只限這個專案建立的檔案），
所以不用自己建立 Google Cloud 專案，也不會有授權過期的問題。

1. 開啟 https://script.google.com ，按「新專案」。
2. 把本專案 `apps-script/Code.gs` 的內容貼進編輯器（取代原有內容）。
3. 把 `const KEY = '…'` 改成你自己的密碼（英文數字，越長越好），記下來。
4. 左側「專案設定」→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。
   回到編輯器，開啟 `appsscript.json`，把內容換成本專案 `apps-script/appsscript.json`。
5. 上方函式選單選 `authorize`，按「執行」，依畫面授權
   （出現「Google 尚未驗證這個應用程式」→ 進階 → 前往（不安全）→ 允許）。
6. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：所有人
   按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 開啟 App →「雲端備份」→ 貼上網址和密碼 →「測試連線」。
   成功後按「立即備份並檢查雲端完整性」。

備份位置：你的 Google Drive 裡的「立即錄音機備份」資料夾。
